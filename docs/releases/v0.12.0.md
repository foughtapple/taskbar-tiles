## Taskbar Tiles 0.12.0

### Cleaner Settings

The old Windows tab strip is gone from the visible Settings interface. Settings now uses a **dark left-hand navigation rail** with grouped pages:

- **General:** Appearance, Navigation, Quick access
- **Launchers:** Favourites, Search, Recent apps
- **Display & input:** Screens & zones, Monitor layouts, Touch screen monitor support
- **Integrations:** Stream Dock, Updates, Startup & tools, Shortcut health

The underlying pages are unchanged, so existing Apply/Cancel behavior, live previews, hover help, Stream Dock management and saved settings continue to work. The native tab headers are collapsed and owner-drawn so Windows cannot reintroduce the white wrapped-tab appearance.

### Discord notification counter

Discord entries in the notification-area row now use a dedicated counter tile:

- **0:** black background
- **1 or more:** red background
- count is large, bold and centred
- counts above 999 display as **999+**

Taskbar Tiles reads common Discord accessibility labels such as `Discord - 1 notification`, `Discord, 27 unread messages` and `Discord (105)`. If Windows/Discord exposes the item as Discord but provides no numeric count, Taskbar Tiles shows **0** rather than trying to infer a number from the icon pixels. Other notification-area items keep their existing icons.

### Existing features retained

This release is based on 0.11.0 and retains the unified Stream Dock modules, notification-area row, auto-hidden taskbar inventory, Search, Recent apps, Touch Return, window activation/topmost fixes, rendering recovery, Steam/app reopening and GitHub updater.

### Update

Use **Settings > Updates > Check for updates... > Download & install**. Do not uninstall first. Existing settings, favourites, recent history, Stream Dock choices, startup preference, X-Mouse command and touch configuration are preserved.

### Validation

Release gates include Windows compilation/helper tests, real Settings-window painting with the dark navigation rail, notification-row geometry and Discord count/color tests, the existing cross-process notification Invoke fixture, Stream Dock package/installer tests, launcher/rendering/click-away/touch/topmost/app-launch tests, updater HTTPS/checksum verification and installer upgrade tests.

CI cannot guarantee that every Discord build exposes an unread number in its tray accessibility name. When the number is not exposed, the displayed count is zero. The installer is unsigned.
