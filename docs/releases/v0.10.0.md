# Taskbar Tiles 0.10.0 — Stream Dock module manager

A new **Settings > Stream Dock** tab brings the final custom controls and displays into Taskbar Tiles' normal release/update lifecycle. The taskbar switcher remains independent.

- Eleven individually selectable actions in five packages: game open/close, zone/monitor screenshot, clipboard history, Ctrl+Alt+Shift+F voice, Smart Steam switch, switch-and-launch Rocket League, P1S, CPU/RAM, NickNacks orders and optional account-status view.
- Existing matching plugin placements and external settings/credentials are preserved. New modules default off. Disable/reenable is reversible and enforced by installed action manifests plus runtime allow-lists.
- Taskbar Tiles updates now carry reviewed module payloads; enabled modules synchronise in place, disabled ones stay off. Setup asks for Stream Dock to be fully closed; it never kills it. Startup reconciliation is one-shot and reports blocked updates as pending.
- SHA-256 verification, traversal/reparse rejection, staged replacement, per-package backup/rollback and journal recovery; no changes to unrelated plugins or Stream Dock profiles.
- Final lightweight polling, P1S reconnect fixes and whole-monitor screenshot fallback retained. Broken Codex Monitor is not included.

## Upgrade

Install this release normally, then open **Settings > Stream Dock**. Select modules and leave **Update enabled modules when Taskbar Tiles updates** checked. Fully exit Stream Dock and choose **Apply Stream Dock choices**. Reopen Stream Dock and drag any new actions from **FoughtApple** under Key/Info board. Existing native plugin placements retain their UUIDs. The new Desktop Controls actions replace old Toolbox/Open shortcuts only when you explicitly assign them.

Future ordinary Taskbar Tiles installers carry enabled plugin updates automatically; there is no separate download/import step. See [complete integration and maintainer instructions](../STREAM-DOCK.md).

Synthetic and Windows CI checks do not claim live verification against a physical 293S, real Steam accounts, P1S or WooCommerce store. Keep original controls until the new placements have been tested on your PC.
