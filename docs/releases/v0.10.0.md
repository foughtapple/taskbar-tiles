# Taskbar Tiles 0.10.0 — Stream Dock module manager

A separate **Settings > Stream Dock** tab brings the final custom controls and displays into Taskbar Tiles' normal release/update lifecycle. The taskbar switcher remains independent, including the existing 0.9.1 app-reopening fixes.

- Ten individually selectable actions in four packages: Rocket League/Overwatch open-close, zone-or-monitor screenshot, clipboard history, Ctrl+Alt+Shift+F voice, Steam Smart Switch, switch-and-launch Rocket League, P1S, CPU/RAM and NickNacks orders.
- Existing matching native plugin placements and external account/printer/store credentials are preserved. New actions default off. Disable/re-enable is reversible and enforced by installed manifests and runtime action allow-lists.
- Ordinary Taskbar Tiles releases carry the module payloads. Enabled modules synchronise in place; disabled actions stay off. Setup requires Stream Dock to be fully closed and never kills it. Blocked startup reconciliation reports pending changes rather than replacing running executables.
- SHA-256 verification, safe archive paths, staged replacement, settings-preserving backups and recovery journals protect package updates. Unrelated plugins and Stream Dock profiles are not changed.
- Five-second visible-only Steam/PC monitoring, P1S reconnect recovery, five-minute order polling and whole-monitor screenshot fallback are retained.
- The obsolete independent Steam status indicator is not reinstated. Any existing copy remains untouched. The problematic third-party Codex Monitor is not bundled.

## First-time setup

1. Fully exit Stream Dock from its system-tray icon and install this release normally.
2. Open **Taskbar Tiles Settings > Stream Dock**. Check the actions you want and leave **Update enabled modules when Taskbar Tiles updates** checked.
3. Choose **Apply Stream Dock choices** while Stream Dock is closed.
4. Reopen Stream Dock and drag enabled actions from **FoughtApple** under **Key** or **Info board**.

Existing Steam Smart Switch, P1S, CPU/RAM and NickNacks Orders action IDs are retained. The new Desktop Controls actions replace the old Toolbox/Open shortcuts only when you explicitly assign them. Keep the old Buttons-Plain directory until you have tested those replacements.

## Future updates

Use Taskbar Tiles' ordinary update button. Close Stream Dock before installing the update, then reopen it afterward. Previously selected plugins update without separate installers; settings and On/Off choices remain. Newly introduced actions appear unchecked. Do not run the older standalone plugin installers over the managed copies.

[Complete setup, storage, recovery and maintainer instructions](https://github.com/foughtapple/taskbar-tiles/blob/main/docs/STREAM-DOCK.md)

Windows CI tests actual package enable/disable/re-enable, installer upgrades, opt-outs and private-setting preservation, plus existing taskbar regressions. These tests do not reproduce the owner's physical 293S, real Steam accounts, P1S or WooCommerce endpoint. The installer is not Authenticode signed.
