## Taskbar Tiles 0.14.0

### Settings text is no longer underneath the sidebar

The editor, navigation rail and live preview now receive separate, measured rectangles. The previous narrow-rail change did not fix their overlapping docking arrangement. The layout adapts to smaller windows by moving the preview below the editor; it never places the sidebar over the settings text. The hidden native tab border is removed as well.

### Real tray apps in the middle; system controls on the right

Application notification icons are centred under Taskbar apps. Language, network, audio, clock and other taskbar system controls sit at the far right of that strip. The reader recognises both the classic overflow window and Windows 11's newer hidden-icons host.

All tray items exposed by Windows remain included by default. If Explorer has not created the hidden-icons surface yet, **Load tray apps...** opens the normal Windows hidden-icons menu on an explicit click; reopen Taskbar Tiles afterwards. Taskbar Tiles does not change Windows visibility/pinning settings or force the tray open in the background.

Visible, unobstructed tray artwork is cached in memory. A window covering the tray is never captured as an icon. Hidden entries without available artwork use a local application icon or a neutral fallback. This displays the actual Discord tray icon where available, rather than inventing an unread count from a label without a number. Right-click item actions remain available.

### Three bottom-bar shortcuts

**Display settings**, **Bluetooth** and **Task Manager** are enabled by default on the bottom bar. Each can be disabled under **Settings > Quick access**. They open the relevant Windows destination, without running a command interpreter or changing system settings automatically.

### Saved organisation for active windows

The header's **Order** button cycles **Recent**, **A-Z** and **Priority**, and remembers the chosen mode.

- **Recent:** retain Windows' current switching order.
- **A-Z:** sort active window titles alphabetically.
- **Priority:** put assigned applications in their saved priority order, followed by unassigned windows. Windows of the same application retain their recent relative order.

The **P** button at the top-left of every active-window card opens a picker with **50 numbered slots**, **ten visible rows**, and scrolling for the rest. Every slot shows its assigned application or **Unassigned**. Selecting an occupied number inserts the app there and shifts entries down to the next free slot. Existing assigned apps can be moved. When no free slot exists, the action is rejected with an explanation instead of silently dropping number 50.

Priorities belong to identified applications, not changing document titles or transient window handles, and survive restarting Taskbar Tiles. **Settings > Window organisation** offers Move up, Move down, Assign number and Remove priority. Changes made there remain a draft until Apply; Cancel/click-away discards unapplied edits. Choosing P or changing the header's Order is an immediate saved action.

### Update and compatibility

Use **Settings > Updates > Check for updates... > Download & install**. Do not uninstall first. Existing favourites, app and preview sizes, startup/X-Mouse preferences, Stream Dock selections, Touch Return configuration and updater protections remain intact. Fully exit Stream Dock if Setup asks before replacing its managed module files.

Release gates include priority insertion/persistence/sorting tests, actual Settings editor containment and painting at wide/narrow sizes, the ten-row priority picker, split tray and footer geometry, and the existing Windows application, rendering, launch, Stream Dock, updater and installer tests. GitHub CI does not reproduce a personalised Windows 11 tray or certify physical Surface/Stream Dock hardware. The installer is unsigned.
