## Taskbar Tiles 0.7.4

### Apps decide whether to open a new window or reuse one

Clicking an app tile now sends its normal launch request and observes the result for ordinary launches as well as monitor/zone launches. It does not decide that an app is single-instance because of its name or because it is already running.

- If the app creates a new window, prefer that window, even when it belongs to an already-running process.
- If the app exposes/focuses an existing window, use that window instead. A single verified existing window that remains covered or minimised can be restored after the configured launch-result wait.
- A program's own single/multiple-instance preference is evaluated by that program on each normal launch. Taskbar Tiles does not read or edit Steam/Bambu settings or maintain a hard-coded app list.
- Right-click placement applies to the identified new or reused window. New windows take priority, and ambiguous placement still asks rather than moving an arbitrary app.
- Preserve exact shortcut arguments, browser-profile identities, PID/creation-time checks, single dispatch, topmost behaviour and the repaired updater.
- Opening the menu, choosing another app, opening Settings or navigating elsewhere cancels stale passive observation, not the already-sent launch. Ordinary shortcuts no longer block the next launch while being observed, and do not trigger an unsolicited placement dialog.

### Settings

Under **Settings > Navigation > Launching and window placement**, **Bring forward an existing window when the app reuses it** is enabled by default. **Wait for the app's launch result** controls the bounded fallback wait; it is not proof that an app is single-instance. A very slow or unidentified application may still need selection through its ordinary window/taskbar entry.

The historical **force a new Terminal window** default is turned off once during this upgrade so app settings govern normal launches. An explicitly labelled optional Terminal override remains available. Explicit custom shortcut arguments are never rewritten. Other settings, favourites and X-Mouse paths are retained.

### Update

Use **Settings > Updates > Check for updates... > Download & install**, or run **TaskbarTiles-0.7.4-Setup.exe** over the existing installation. Do not uninstall first.

### Validation

Publication is gated on Windows compilation, deterministic regression tests, native launch/outcome tests using disposable out-of-process fixture windows with switchable single/multiple-instance preferences, existing native topmost tests, actual updater HTTPS/download/checksum tests and installer install/upgrade/uninstall tests. Fixtures exercise multiple-window creation, reused and minimised windows, and delayed new-window placement without relaunching.

Steam, Bambu Studio and the reporter's exact desktop are not installed or reproduced by those fixture tests. Windows foreground restrictions and ambiguous app identities still apply. Installer unsigned; SHA-256 verifies download integrity, not an independent publisher identity.
