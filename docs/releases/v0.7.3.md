## Taskbar Tiles 0.7.3

### Fix: the switcher appears behind other apps

The reusable switcher previously set TopMost once in its constructor and relied on Show/Activate on subsequent opens. That does not explicitly restore its place above other topmost windows or repair a lost native topmost flag.

- Reassert the switcher's own native topmost position on every open, before and after activation, and when it regains focus.
- While the switcher is in use, repair lost topmost state or an overlapping window above it without stealing keyboard focus.
- Stop that maintenance before handing focus to the selected app, hiding, opening another Taskbar Tiles dialog or shutting down. A stale timer cannot show a dismissed menu.
- Preserve the exact-window activation fix, asynchronous restore handling and user-input-aware retry limits. Other applications are not made permanently topmost or demoted.
- Keep owned dialogs, dropdowns and tooltips above their parent.
- Correct the tray's version label so it uses the installed version rather than a hardcoded older label.

### Update from the app

On 0.7.2, use **Settings > Updates > Check for updates...**, then **Download & install** for 0.7.3. Follow the normal Setup wizard. Do not uninstall first. Settings, favourites, monitor layouts and mouse shortcuts are preserved.

All updater TLS/security fixes from 0.7.2 and placement fixes from 0.7.1 remain. Users still on 0.7.0/0.7.1 whose updater cannot connect can use the browser download instead.

### Validation

Publication requires Windows compilation, existing regression tests, new topmost-lifetime tests, native Win32 Z-order tests using disposable Forms (including competing topmost windows, hide/reopen cycles, cached/native state mismatch and safe handoff), the real updater HTTPS/download/checksum test and installer install/upgrade/uninstall tests.

These tests do not reproduce the user's exact desktop or certify every game/third-party overlay. A normal desktop utility cannot appear over Windows' secure desktop; exclusive fullscreen and deliberately competing overlays can have additional restrictions. The existing fullscreen-minimise option is retained.

The installer is unsigned. SHA-256 verifies download integrity, not an independent publisher identity.
