## Taskbar Tiles 0.11.0

### Notification-area row

Taskbar Tiles now mirrors Windows notification-area (system-tray) items in a compact single row between **Taskbar apps** and the footer. The row remains available when the Windows taskbar itself is auto-hidden.

- Default notification icon size is 26 logical pixels and can be adjusted from 16 to 48 under **Settings > Appearance**.
- Spacing is independently adjustable from 2 to 24 logical pixels.
- The row stays single-line. When more items exist than fit, previous/next controls page through them.
- Ctrl+mouse-wheel over the notification row changes its icon size quickly.

### Tray item actions

Left-click asks the actual Explorer notification item for its normal/default accessibility action. Right-click opens a Taskbar Tiles menu with:

- **Open / default action**
- **Open native tray menu**
- **Copy name**
- **Windows taskbar settings**
- **Refresh notification area**

Taskbar Tiles refreshes the actual item before acting; it does not click saved/hidden screen coordinates, force the auto-hidden taskbar open, scrape Explorer memory, or inspect notification message contents.

When an item's application can be matched unambiguously to an installed app, Taskbar Tiles uses that app's icon. Otherwise it displays a neutral initials tile rather than guessing.

### Existing features retained

This release is built on 0.10.1 and retains the unified Stream Dock modules, app reopening fixes, auto-hidden taskbar inventory, Search, Recent apps, Touch Return, activation/topmost fixes, rendering recovery and secure GitHub updater.

### Update

Use **Settings > Updates > Check for updates... > Download & install**. Do not uninstall first. Existing settings, favourites, recent history, Stream Dock choices, startup preference, X-Mouse command and touch configuration are preserved.

### Validation and limits

Release gates cover Windows compilation and helper tests, notification-row geometry and policy checks, a disposable cross-process default-action fixture, existing app reopen/launcher/rendering/click-away/touch/topmost/launch tests, updater HTTPS/checksum verification, and installer/Stream Dock upgrade tests.

CI does not reproduce the user's personalised Windows 11 notification area or every third-party tray provider. A tray app that does not expose a usable accessibility Invoke action may still appear in the row but cannot be opened from the mirror. The installer is unsigned.
