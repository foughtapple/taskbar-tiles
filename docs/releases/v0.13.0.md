## Taskbar Tiles 0.13.0

### Fresh-install integration choices

Setup now makes the two optional integrations explicit on a **fresh install**:

- **Stream Dock integration — ON by default.** Installs/enables the complete bundled Taskbar Tiles action set in the single unified Stream Dock category and turns module auto-update on.
- **Touch Return — OFF by default.** The feature is included, but its installer checkbox is unchecked. If checked, Setup enables only the master switch; automatic mouse/focus return still requires a successful touchscreen/pen detection and monitor association in Settings.

These defaults apply only to a fresh installation. **Upgrades never replace an existing user's Stream Dock per-action choices, auto-update preference or Touch Return setting.**

If Stream Dock is running during a fresh install, Taskbar Tiles records the Stream Dock choice and reports the package operation as pending instead of killing Stream Dock. Fully exit Stream Dock and use **Settings > Stream Dock > Apply** to reconcile it.

### Better notification-area row

The compact tray row now defaults to **all detected notification-area items**, including hidden/overflow entries. Settings > Appearance has a **Show all tray items** switch for visible-only users.

For each non-Discord tray item, Taskbar Tiles first attempts to copy the visual that Windows itself renders for that notification-area control. This avoids generic/incorrect app artwork and keeps status variants where the shell exposes them. If Windows cannot render that hidden/off-screen control through its window surface, Taskbar Tiles falls back to a strongly matched installed-app icon, then neutral initials rather than guessing.

Discord keeps the dedicated unread counter introduced in 0.12.0.

### Smaller Settings navigation

The dark Settings sidebar is narrower (172 logical pixels instead of 205), with long page names safely ellipsised. The live preview and settings content get more horizontal space.

### Existing features retained

This release includes the API-free updater fix from 0.12.1, dark Settings navigation, Discord unread state, unified Stream Dock module manager, Search, Recent apps, Touch Return, exact-window activation, rendering recovery and installer data preservation.

### Validation

Release gates cover Windows compilation/helper tests, real cross-process tray-image PrintWindow/crop testing, all-item/default notification settings, Stream Dock fresh-install default state, actual Setup fresh-install defaults, upgrade preservation, Touch Return default/installer backend, Settings rendering, updater HTTPS/checksum download, Stream Dock migration/installer tests, launcher/click-away/topmost/touch/app-launch tests.

Real Windows 11 tray providers differ; when a hidden provider cannot be rendered by the shell, the fallback icon path is used. The installer remains unsigned.
