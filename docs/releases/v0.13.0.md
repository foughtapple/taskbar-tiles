## Taskbar Tiles 0.13.0

### Installer integration choices

Setup now exposes two optional integration choices:

- **Taskbar Tiles Stream Dock integration — ON by default.** On a fresh install this seeds all bundled Taskbar Tiles Stream Dock actions and automatic module updating. If an existing Stream Dock state file is present, Setup does not replace the user's per-action choices.
- **Touch Return — OFF by default.** Selecting it enables the master feature switch only. Automatic mouse/focus return still cannot run until a touchscreen/pen device and monitor pass the in-app detection/association checks.

The choices are available in the normal installer opened by the in-app updater.

### Tray row

- **Show all Windows tray items** is now on by default, including hidden/overflow entries that Windows exposes through accessibility.
- Visible notification items prefer a capture of the **actual tray artwork** Windows is currently drawing.
- Hidden/offscreen items fall back to the application's local icon or neutral initials because Windows does not always expose drawable tray pixels while hidden.
- Discord retains its dedicated black-zero/red-positive unread counter tile.

### Settings

The dark left navigation rail is narrower and is rebuilt once Settings is fully shown, so it uses less horizontal space and reflects the final settings-page collection. Long labels such as Touch screen monitor support use shorter navigation text while the actual page title/content remains unchanged.

### Existing features retained

Includes the 0.12.1 API-free GitHub updater, dark Settings, notification row, Discord counter, unified Stream Dock package, Search, Recent apps, Touch Return, app reopening, rendering/activation fixes and settings preservation.

### Validation

Release gates cover compilation/helper tests, notification geometry/defaults, settings navigation, updater HTTPS/checksum verification, installer upgrade/settings preservation and the existing Stream Dock/launcher/rendering/touch/topmost/app-launch suites. Physical tray artwork and Stream Dock hardware remain machine-specific.

The installer remains unsigned.
