## Taskbar Tiles 0.7.6

### Both reported symptoms are covered

This update includes the complete 0.7.5 rendering repair and adds reliable click-away handling for the main menu and Settings. You can update directly from 0.7.4 or an earlier supported version; there is no need to install 0.7.5 first.

### Fix: clicking outside sometimes leaves the menu open

A topmost window can be visible without ever obtaining keyboard/foreground activation. In that state, clicking another app does not necessarily produce the Deactivate event on which the old menu relied.

- Observe outside left/right/middle mouse-down events independently of activation. The event is not consumed; the app or desktop underneath still receives the click.
- Ignore clicks inside Taskbar Tiles, embedded Search, owned dialogs, file pickers and dropdowns. Preserve the X-Mouse toggle path.
- Reject delayed observations from an earlier open/hide session. Dismissal disarms observation, and hidden menus cannot be revived by it.
- Retain settled focus-loss handling when the menu did obtain focus, while avoiding immediate dismissal when initial activation was denied.
- Respect the existing **Close the menu and Settings when clicking outside** setting. Settings discards unapplied changes and unwinds its owned dialogs; explicit Apply saves are not undone.

### Included: white menu / red-X repair

The 0.7.5 fix remains intact: reuse owned menu fonts, rebind controls before disposing replaced fonts, isolate bad icons and contain managed paint failures with bounded recovery. The native regression reproduces the prior equal-font/disposal defect and exercises the real menu/preview path. The exact original exception on the reporter's machine was not supplied, so the screenshot does not prove which draw failed.

A persistent rendering problem can be retried with **F5** or tray **Refresh menu graphics**. Tray **Open rendering diagnostics** opens the bounded local log; no screenshots, window titles, search queries or click coordinates are captured by these diagnostics.

### Update

Use **Settings > Updates > Check for updates... > Download & install** for 0.7.6. Do not uninstall first. Settings, favourites, sizes, monitor layouts, X-Mouse shortcuts, app-managed single/multiple-instance behavior, topmost handling and secure updater fixes are retained.

### Validation and limitations

Publication requires Windows compilation and helper regressions, real-menu rendering/recovery tests, real outside-click tests against a disposable nonactivating process (including unchanged click delivery, stale-session rejection, internal-click exclusions and disabled-preference behavior), existing native topmost and app-launch tests, production HTTPS/download/checksum verification and installer install/upgrade/uninstall smoke tests.

These are controlled Windows-runner tests, not a reproduction of the reporter's exact desktop, display driver or original exception. The installer remains unsigned. No Windows security settings are changed.
