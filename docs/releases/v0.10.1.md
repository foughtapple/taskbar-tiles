# Taskbar Tiles 0.10.1 — one Stream Dock category

The ten managed actions now appear in a single expandable **Taskbar Tiles** section instead of repeated FoughtApple sections. The normal taskbar switcher is unchanged.

- One outer plugin owns the SDK connection and routes text-framed events to the existing Steam, P1S/CPU, NickNacks and desktop-control workers over loopback. No cloud bridge or AI calls.
- All ten existing action UUIDs and individual On/Off choices are retained. Disabled groups are not launched; visible-only monitoring stays in the workers.
- The ordinary 0.10.0 -> 0.10.1 app update imports private files from active and previously disabled worker folders before overlaying bundled code. Existing external account, printer and store credentials remain in their per-user locations.
- The four old active managed plugin folders are archived, not discarded. Newer/unrecognised legacy workers are refused rather than downgraded. A partial or interrupted migration restores the old folders together instead of exposing duplicate categories.
- The bridge queues first-appearance events during startup, validates context ownership, bounds queues/logs, and closes its own workers when Stream Dock disconnects.

## Install through the app

1. Fully exit **Stream Dock** from its Windows tray icon.
2. In **Taskbar Tiles > Settings > Updates**, choose **Check for updates**, then download and install **0.10.1**. Do not uninstall first.
3. With **Update enabled modules when Taskbar Tiles updates** enabled, the installer migrates your selected modules automatically. When it is disabled, or the page reports pending consolidation, use **Settings > Stream Dock > Apply Stream Dock choices** with Stream Dock closed.
4. Reopen Stream Dock. Use **Taskbar Tiles** under **Key** for buttons and **Info board** for viewers. Those are separate filtered tabs, not separate plugins.

Action UUIDs are preserved without rewriting your Stream Dock profiles. Some host versions may also bind an assignment to its former plugin identity: if an old placement shows unavailable, drag its matching action back from Taskbar Tiles once. Saved external connection settings are not reset.

The separately installed, obsolete **Steam Account Status** monitor is not one of the four managed packages. An old FoughtApple heading containing only that monitor can remain; it is left untouched, as are all unrelated third-party plugins.

## Validation boundary

Release gates build the Windows plugin/installer, exercise real child-worker connections and display messages against a simulated Stream Dock host, test migration from the checksum-pinned published 0.10.0 installer, and test rollback, private settings, disabled actions and opt-outs. Existing Taskbar Tiles native regression suites also run. Passing CI does not reproduce a physical 293S, the owner's real Steam accounts, P1S, or WooCommerce endpoint. The installer is unsigned.
