# Taskbar Tiles 0.10.1 — one Stream Dock category

Stream Dock now shows the managed actions under one expandable **Taskbar Tiles** section rather than one repeated section for each plugin package.

- All ten 0.10.0 actions keep their existing action UUIDs.
- The unified plugin uses a local loopback bridge to the same tested Steam, P1S/CPU, NickNacks and desktop-control workers. No cloud bridge or model call is added.
- Updating from 0.10.0 maps the existing managed-package state to the unified package. With Stream Dock closed, old managed plugin folders are archived in the Taskbar Tiles backup directory and the unified package is installed.
- Existing external Steam account, printer and NickNacks credentials remain in their current per-user locations.
- Per-action On/Off selections are retained. Future Taskbar Tiles releases update this single package through the normal updater.

## Update

Fully exit Stream Dock from its tray icon, then use **Taskbar Tiles > Settings > Updates > Check for updates** and install 0.10.1. Reopen Taskbar Tiles > Settings > Stream Dock and click **Apply Stream Dock choices** if the page reports legacy actions waiting to consolidate. Reopen Stream Dock afterward.

The physical 293S and the owner's live Steam/P1S/WooCommerce accounts remain user-side validation; CI covers the unified bridge/package build, migration, rollback, settings preservation and existing Taskbar Tiles regressions.
