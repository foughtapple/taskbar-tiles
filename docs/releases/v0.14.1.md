## Taskbar Tiles 0.14.1

### Tray right-click crash

The tray context menu is no longer disposed from inside its Closed event. Windows Forms still uses the menu while unwinding its close operation; that caused the reported ObjectDisposedException and could terminate the message loop. The repaired menu is reused across openings. Commands and final disposal are queued after the close path completes.

### Real tray artwork while the overflow is hidden

The icon reader now also reads Windows' saved IconSnapshot PNG artwork, using read-only access to the current user's notification-icon cache. It only associates a saved image with an unambiguous matching entry already present in the live tray list. Old cache records do not create ghost tray items.

Visible, unobstructed live icons still take precedence. Windows-saved icons can lag current status; the tooltip identifies their source. If no valid image can be obtained, a neutral application symbol replaces the previous letter/initials tile. A snapshot without a numeric unread count is not presented as a verified zero.

Right-click includes **Load / refresh Windows tray images**, **Refresh tray items**, and **Copy tray diagnostics**. The latter copies a local report of image sources and accessibility metadata; nothing is uploaded. The reader does not alter tray visibility, pinning or registry values. Windows' saved-image format is a compatibility fallback, not a guaranteed public API.

### Preservation and update

Use **Settings > Updates > Check for updates > Download & install**. Do not uninstall first. Settings layout, active-window priorities, the three system shortcuts, centred tray apps/right-aligned system controls, Stream Dock choices, Touch Return and the API-free updater remain.

### Tests and limits

The notification test gate now runs the production menu through repeated close/reopen, outside-click and queued-action cases, plus PNG decoding, transparency, size limits and ambiguous-record matching tests. Existing Windows build, settings/priority, launcher, touch, Stream Dock, updater and installer gates remain required. Tests run on Windows CI, not the user's personalised desktop. The installer is unsigned.
