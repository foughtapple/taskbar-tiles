## Taskbar Tiles 0.12.1

### Updater 403 repair

The updater no longer depends on GitHub's unauthenticated REST API to discover the latest version. That API has a low shared-IP rate limit and can return **HTTP 403 Forbidden** even while the public release page and installer remain available.

Taskbar Tiles now:

1. resolves GitHub's normal public **/releases/latest** redirect;
2. validates that the redirect points back to this repository and a strict `vX.Y.Z` tag;
3. fetches that release's **SHA256SUMS.txt**;
4. requires a valid hash for the exact expected installer before enabling **Download & install**;
5. downloads the installer only from the existing trusted GitHub release hosts and verifies its SHA-256 before opening Setup.

No GitHub token, credentials, machine-wide TLS change or certificate bypass is used.

### One-time update note for 0.10.x / older updater builds

A build that is already failing with the old HTTP 403 updater cannot download its own updater repair. Install 0.12.1 once through the browser over the existing installation; do **not** uninstall first. After that, normal in-app updates use the API-free path.

### Existing features retained

This release includes the 0.12.0 dark Settings navigation and Discord unread counter, plus the unified Stream Dock modules, notification-area row, Search, Recent apps, Touch Return, app reopening and all existing settings.

### Validation

Release gates include the actual compiled executable resolving GitHub's public latest-release redirect, fetching the checksum list, downloading the released installer, verifying SHA-256 and the Windows Internet security marker, then deleting the test download without executing it. Existing installer/Stream Dock, Settings rendering, notification, launcher, touch, topmost and app-launch suites also run.

The installer remains unsigned.
