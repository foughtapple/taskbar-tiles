## Taskbar Tiles 0.8.0

### Shortcut reliability and click-away

An ordinary menu exception could previously leave Alt+Tab interception disabled until restart or a settings reload. The new recovery path preserves the saved preference, repairs after a short bounded pause, and records the reason in local shortcut diagnostics. It does not globally change Windows settings.

The keyboard hook now queues events rather than invoking UI work from the low-level callback. Registrations are renewed between gestures, explicit reopening repairs the resident shortcut path, and wake/unlock requests a repair. Windows can silently remove a timed-out low-level hook; a stored handle alone is not evidence that it is still installed.

**Settings > Shortcut health** and tray **Repair shortcuts** provide a manual repair and local log. Native Ctrl+Alt+Space and the existing X-Mouse Run Application `--toggle` command remain independent ways to open the app. A per-game X-Mouse profile using Windows' own ALT-TAB action is still separate configuration. These fixes do not claim a process crash was diagnosed without a local log.

This release also includes the previously staged outside-click repair: clicks dismiss the menu even if it never obtained activation, without consuming the other application's click. Settings still discards unapplied changes. All 0.7.5 rendering recovery, app-managed launch, topmost and secure updater fixes are retained.

### Touch screen monitor support — experimental, off by default

A new Settings tab implements **Touch Return**: temporarily use a specifically enabled touchscreen and, after all verified contacts end and the configured idle period passes, return to the previous window/cursor without clicking.

- Touch default **1000 ms**, pen default **2000 ms**; separate global and per-monitor timings, nickname, touch/pen switches and hardware-identity associations.
- Passive input-detection test before enabling a device. Complete digitizer reports and corroborating pre-touch state are required. Mouse-only virtual input, incomplete contact reports, ambiguous identities and missing required hover signals stay inactive.
- All contacts must end; no return during a stationary press, a partial multitouch frame, or supported pen hover when enabled. Mixed sessions use the longer delay.
- Physical/unclassified mouse or trackpad use always cancels; typing cancellation is on by default. Stay here, Pause and Return now are available from the tray, with optional unassigned global shortcuts.
- Focus + cursor, focus-only and cursor-only modes; no fake clicks, pointer capture/replay, app injection, forced cursor unclipping or focus-stealing loop. Return requests are bounded and checked.
- Device/display/session changes discard pending returns and require a fresh input test before automatic return resumes.

**Compatibility is not assumed.** This first provider accepts a strict subset of HID touch/pen report formats and requires a matching pre-delivery touch/pen mouse-promotion snapshot from a different screen. An input path that activates its target before that snapshot, suppresses mouse promotion, or exposes only a virtual mouse cannot safely auto-return with this provider. The UI shows diagnostics instead of guessing. Same-screen foreground return is intentionally not inferred. Some spacedesk/Apollo modes may therefore be detection-only. Their actual hardware and drawing path must be tested locally and separately.

The passive test intentionally stays open while you use other applications; automatic return is disabled for its entire lifetime. Close it to resume ordinary Settings click-away. Use draft, then Apply in main Settings, to save an association. Cancel discards it. No device is enabled automatically by this upgrade.

### Update

Use **Settings > Updates > Check for updates... > Download & install**. Do not uninstall first. Settings, favourites, startup choice and X-Mouse paths are retained. This release incorporates the unshipped 0.7.6 click-away changes; there is no need to install intermediate versions.

### Validation and limits

Publication requires Windows compilation, all existing rendering/launch/topmost/HTTPS-download/checksum/installer tests, native outside-click regressions, Touch Return state/contact-frame/cancellation tests, and actual passive input registration plus removed-keyboard-hook recovery tests. No physical touchscreen, Surface, spacedesk, Apollo, pressure/tilt/eraser or palm rejection is certified by CI. A local passive test is mandatory. The installer is unsigned; SHA-256 verifies integrity, not an independent publisher identity.
