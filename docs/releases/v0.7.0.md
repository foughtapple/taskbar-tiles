## Taskbar Tiles 0.7.0

A mouse-first Windows switcher, app launcher and monitor/zone picker.

### Fix: selecting a covered window

Activation is requested before the switcher hides. The app verifies the exact selected window reaches the foreground, waits for an asynchronous restore and uses limited retries only while it is safe. Another top-level window from the same process no longer counts as a successful switch. Only a blocking owned modal dialog can substitute for its disabled owner. New input cancels retrying instead of stealing focus back.

### Proper installation and updates

- Per-user Setup wizard, Start menu entry, startup option and normal Installed Apps uninstaller.
- In-place migration from source-built versions; existing settings, favourites and X-Mouse paths remain.
- Timestamped backup before an upgrade. Uninstall keeps user data.
- User-initiated GitHub update check, release notes, checksum-verified download and normal installer wizard.
- About/version metadata and local switching diagnostics.

All existing search, favourites, text/icon sizing, balanced rows, previews and monitor/FancyZones placement features remain.

### Install

Download **TaskbarTiles-0.7.0-Setup.exe** below and run it normally. **Do not uninstall the previous version first.** Setup uses the same per-user folder. Do not run an old ZIP's uninstaller after upgrading.

Requires Windows 10/11 and .NET Framework 4.8. No Git or compiler needed for this installer. Windows 11 is the primary manual-testing target.

### Verification and limitations

This release is published by CI only after its Windows build, helper tests and installer lifecycle smoke tests pass. See **build-info.json** for the exact commit/run. Those checks do not certify interactive focus/fullscreen behaviour on every application or display setup. Windows foreground restrictions and app-specific behaviours still apply.

**Unsigned build.** SHA256SUMS.txt detects corruption; it is not an independent publisher signature. Do not disable Windows security to install.
