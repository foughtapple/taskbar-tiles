# Taskbar Tiles 0.15.0

Chrome profile shortcuts retain their launch arguments, and Steam uses its registered launcher. Tray items show names, refresh after clicks, and retain reusable action menus.

Right-click a window or taskbar app to use the FancyZone of the window active before opening Taskbar Tiles. Without FancyZones it uses the full monitor. The corner button chooses another screen or zone.

Create named layouts in Settings → Profile layouts. The footer Profile layout button opens missing apps and arranges them; right-click moves only apps already open. Layouts preserve shortcut arguments, skip ambiguous matches and require valid saved monitor destinations. A progress window reports results and allows cancellation.

Settings → Modules installs Stream Dock separately and lets you select its functions. App and module auto-updates are separate opt-ins. Core upgrades preserve module code and private settings. Touch Return is marked Developing and remains inactive.

Also fixes foreground retry ownership, shortcut recovery on queue overflow, oversized Steam avatars and concurrent Steam account/game transitions.

Builds remain unsigned. Native CI tests use disposable fixtures; actual Steam accounts, Stream Dock hardware, printer and store endpoints require testing on their real devices.
