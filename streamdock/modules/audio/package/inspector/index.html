Audio Control

Press to mute or unmute the current Windows default input microphone. The button follows changes to your default input and updates when another app changes its Windows mute state.

MIC LIVE means the Windows endpoint is unmuted. MIC MUTED means that endpoint is muted. NO MIC or MIC ERROR means its status is unavailable.

If you change microphones during a press, the button refreshes safely; press again to control the new default.

Uses the ordinary Windows default input device. Apps using a different microphone or a separate default communications device keep their own input choice. Hardware mute switches and an app's own mute button may have a separate state. No audio is recorded.
